Lashy Sound
===========

Lashy Sound is a tidal-array lease area in Orkney.

**Development status:** The site is not currently under development. See the
`Lashy Sound tidal-array scoping report <https://tethys.pnnl.gov/publications/lashy-sound-tidal-array-scoping-report>`_.

**Why the site is useful:** The earlier scoping work provides a useful
starting point for reviewing how resource assessment, environmental evidence,
and consenting assumptions evolve before a project reaches construction. It
can also inform comparative studies of potential Orkney tidal-array sites.

**Site challenges:** Any future project would need to update the resource,
environmental, and consenting evidence prepared for the earlier scoping work
before deployment. Available site data are limited, so renewed field surveys
would be needed to underpin updated assessments.
