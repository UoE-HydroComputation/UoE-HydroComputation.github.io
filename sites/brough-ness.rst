Brough Ness
===========

Brough Ness is a tidal-lease area in the Pentland Firth.

**Development status:** There is no current development at the site.

**Why the site is useful:** Brough Ness offers a prospective Pentland Firth
location for investigating how far flow structures generated by nearby islands
extend into a lease area. This is useful for assessing the value of spatially
resolved measurements over a single-point resource estimate.

**Site challenges:** The site is partly exposed to large-scale vortices
generated off Swona, which can introduce pronounced spatial and temporal
variation in the tidal flow. Available site data are limited, so additional
measurements would be needed to resolve these structures confidently.
