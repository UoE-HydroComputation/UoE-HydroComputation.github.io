MeyGen Inner Sound
==================

The MeyGen Inner Sound in the Pentland Firth hosts the MeyGen tidal-stream project.
It is one of the UK's most energetic tidal-stream locations.

**Development status:** MeyGen is an operating tidal-stream project. See the
`MeyGen project overview <https://ampeak.energy/tidal-stream/meygen/>`_.

**Why the site is useful:** As a commercial-scale array location with an
established operational history, MeyGen provides an important case for testing
resource assessment, array-wake modelling, turbine performance, and
operational planning in energetic tidal currents.

**Site challenges:** The flow has strong tidal asymmetry, so turbines need
yaw-capable rotors to remain aligned with the changing current. Sharp
bathymetric changes also produce challenging local flow conditions; see
`Angeloudis et al. (2025) <https://www.tandfonline.com/doi/full/10.1080/00221686.2025.2554989>`_.
